# Redstar — интерактивный лендинг

Текущая согласованная версия главной страницы Redstar: стеклянная шапка, цифровая мастерская, анимации услуг и кейсов, карусель отзывов и консультация с основателями.

## Просмотр

GitHub Pages публикуется из ветки `main`, папки `/`.

## Локальный запуск

```sh
python -m http.server 8765
```

Откройте http://localhost:8765/.

Проект статический: HTML, CSS, JavaScript и локальные изображения/шрифты. Сборка не требуется. Исходные дополнительные страницы и предыдущие версии ресурсов сохранены для дальнейшей работы; главная страница использует текущую версию оформления.

## Формы

Серверный обработчик заявки пока не подключён. Форма сообщает об этом и предлагает телефон/Telegram. Telegram-ссылка работает.
